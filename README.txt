Healthy Mine - Daily Boost
Website Mockup — Project Files
===============================

HOW TO VIEW
-----------
Just double-click "index.html" to open it in any web browser
(Chrome, Edge, Firefox, Safari). No server or installation needed —
it is a single self-contained page plus a local "images" folder.

WHAT'S INSIDE
-------------
index.html     - the full website (all pages, styles and scripts
                 in one file: Home, About Us, Products, Our
                 Difference, FAQs, Contact)
images/        - the 6 product jar photos used on the site

NOTES
-----
- This is a MOCKUP for client review. Product details, pricing,
  ingredients, claims, the Sign In system, Cart/Checkout flow and
  the Contact page map link are all sample content — nothing is
  connected to a real backend, payment system or database.
- The page is fully responsive (desktop, tablet, mobile).
- To make further changes, edit index.html directly — all markup,
  CSS and JavaScript live in that one file for easy editing.
